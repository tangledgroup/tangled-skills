# C4 Diagrams

C4 model diagrams for software architecture: Context, Container, Component, Dynamic, and Deployment views. Compatible with plantUML C4 syntax.

## Diagram types

| Keyword | Description |
| --- | --- |
| `C4Context` | System context diagram |
| `C4Container` | Container diagram |
| `C4Component` | Component diagram |
| `C4Dynamic` | Dynamic (interaction) diagram |
| `C4Deployment` | Deployment diagram |

## Elements

### People

```
Person(id, "Name", "Description")
Person_Ext(id, "Name", "Description")   %% External person
```

### Systems

```
System(id, "Name", "Description")
System_Ext(id, "Name", "Description")    %% External system
SystemDb(id, "Name", "Description")      %% Database system
SystemDb_Ext(...)
SystemQueue(id, "Name", "Description")   %% Queue system
SystemQueue_Ext(...)
```

### Containers

```
Container(id, "Name", "Technology", "Description")
ContainerDb(...)
ContainerQueue(...)
Container_Ext(id, "Name", "Technology", "Description")  %% External container
ContainerDb_Ext(...)
ContainerQueue_Ext(...)
Container_Boundary(id, "Label") { ... }
```

### Components

```
Component(id, "Name", "Technology", "Description")
ComponentDb(...)
ComponentQueue(...)
Component_Ext(id, "Name", "Technology", "Description")  %% External component
ComponentDb_Ext(...)
ComponentQueue_Ext(...)
```

### Boundaries

```
System_Boundary(id, "Label") {
    System(s1, "System 1")
}
Enterprise_Boundary(id, "Label") {
    Person(p1, "User")
}
Boundary(id, "Label", "Type") {
    ...
}
```

Boundaries can be nested.

## Relationships

```
Rel(source, target, "Description", "Technology")
Rel_U(source, target, "Description")     %% Up
Rel_D(source, target, "Description")     %% Down
Rel_L(source, target, "Description")     %% Left
Rel_R(source, target, "Description")     %% Right
BiRel(source, target, "Description")     %% Bidirectional
Rel_Back(target, source, "Description")  %% Reverse direction from target
```

Named parameters with `$` prefix:

```
UpdateRelStyle(customerA, bankA, $offsetX="-40", $offsetY="60", $lineColor="blue")
```

## Styling

```
UpdateElementStyle(id, $fontColor="red", $bgColor="grey", $borderColor="red")
UpdateRelStyle(src, tgt, $textColor="blue", $lineColor="blue", $offsetX="5", $offsetY="-10")
```

### Deployment nodes (C4Deployment)

```
Deployment_Node(id, "Name", "Technology", "Description")
Node(id, "Name", "Type", "Description")        %% Shorthand for Deployment_Node
Node_L(id, "Name", ...)                         %% Left-aligned node
Node_R(id, "Name", ...)                         %% Right-aligned node
```

Nodes can be nested to represent infrastructure hierarchies.

## Layout config

```
UpdateLayoutConfig($c4ShapeInRow="3", $c4BoundaryInRow="1")
```

Default: `c4ShapeInRow=4`, `c4BoundaryInRow=2`. Adjust to control how many elements fit per row.

## C4Context example

```
C4Context
    title System Context for Internet Banking
    Enterprise_Boundary(b0, "BankBoundary") {
        Person(customer, "Banking Customer", "A customer with personal accounts.")
        System(banking, "Internet Banking System", "Allows customers to view accounts and make payments.")
        SystemDb_Ext(mainframe, "Mainframe Banking System", "Stores core banking information.")
    }
    Rel(customer, banking, "Uses")
    Rel(banking, mainframe, "Uses")
```

## C4Container example

```
C4Container
    title Container Diagram for Internet Banking
    Person(customer, "Customer", "A customer of the bank.")
    System_Ext(email, "E-Mail System", "Internal e-mail system.")
    Container_Boundary(c1, "Internet Banking") {
        Container(spa, "Single-Page App", "JavaScript, Angular", "Provides banking functionality via web browser.")
        ContainerDb(database, "Database", "SQL Database", "Stores user registration and auth data.")
    }
    Rel(customer, spa, "Uses", "HTTPS")
    Rel(spa, database, "Reads from and writes to", "JDBC")
```

## C4Component example

```
C4Component
    title Component Diagram - API Application
    Container(spa, "SPA", "JavaScript", "Frontend application.")
    ContainerDb(db, "Database", "SQL", "User data store.")
    Container_Boundary(api, "API Application") {
        Component(signin, "Sign In Controller", "MVC Rest Controller", "Handles authentication.")
        Component(security, "Security Component", "Spring Bean", "Auth logic.")
        Rel(signin, security, "Uses")
        Rel(security, db, "Read & write", "JDBC")
    }
    Rel_Back(spa, signin, "Uses", "JSON/HTTPS")
```

## C4Dynamic example

```
C4Dynamic
    title Dynamic Diagram - Sign In Flow
    ContainerDb(db, "Database", "SQL", "User data.")
    Container(spa, "SPA", "JavaScript", "Frontend.")
    Container_Boundary(api, "API Application") {
        Component(security, "Security", "Spring Bean", "Auth logic.")
        Component(signin, "Sign In Controller", "MVC Rest Controller", "Handles login.")
    }
    Rel(spa, signin, "Submits credentials", "JSON/HTTPS")
    Rel(signin, security, "Calls isAuthenticated()")
    Rel(security, db, "select * from users", "JDBC")
```

## C4Deployment example

```
C4Deployment
    title Deployment Diagram - Live
    Deployment_Node(server, "Server", "Ubuntu 16.04 LTS") {
        Deployment_Node(tomcat, "Apache Tomcat", "Tomcat 8.x") {
            Container(api, "API Application", "Java", "Provides banking API.")
        }
        Deployment_Node(oracle, "Oracle", "Oracle 12c") {
            ContainerDb(db, "Database", "SQL", "User data.")
        }
    }
    Rel(api, db, "Reads/writes", "JDBC")
```
